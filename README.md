# My-Python-Learning-Journey
深圳大学心理学院 Python平时作业
> 本仓库代码参考知识点：输入输出、算术运算、if分支、while循环。

## 文件清单
1. bmiexponent.py：BMI身体质量指数计算程序（作业01）
2. whileLoop_01.py：while循环数羊示例（课件原版，作业01）
3. emotion_sum.py：情绪评分循环统计程序（作业02，举一反三）

## 代码说明
### bmi.py【作业01】
**课件知识点：**
input()输入、float()类型转换、算术运算符、if-elif-else多分支判断、print输出
程序逻辑：
接收身高、体重，计算BMI值，根据BMI区间判断体型等级。

### whileLoop_01.py【作业01】
**课件知识点：while循环、循环变量更新**
程序逻辑：
初始化计数变量sheepCounted=0，while判断计数小于30就持续循环打印；每次循环计数+1，循环结束后打印入睡提示。
课件原版示例：模拟数羊，循环直到数到30。

### emotion_sum.py【作业02】
**课件知识点：while循环、循环变量、输入、累加**
> 举一反三说明：参考课件数羊while循环框架，不直接复制课件代码，改成心理学实验场景。
程序逻辑：
设置循环次数，依次录入5名被试的情绪评分，while循环不断读取分数、累加总分；循环结束后计算并且输出总分、平均分。
和课件数羊结构一致：初始化变量 → while条件判断 → 循环内执行操作 → 更新计数器。

## 运行方式
Python3.x，cmd终端执行
